Projects

Selected work

FinTech AI-Screener

Python, pandas, yfinance, Ollama

Automated market data pipeline that screens stocks and combines classic technical indicators with an AI-based risk assessment.

  • Loads market data via yfinance and processes it with pandas
  • Calculates RSI and moving averages itself and derives buy and sell signals
  • A locally hosted language model (Ollama) assesses the risk of each signal
  • Presents the results in charts and an HTML dashboard
Source code

Kafka Market Stream

Java, Apache Kafka, PostgreSQL

Real-time data pipeline modelled on how trading systems process price events.

  • A price generator streams market events through Apache Kafka
  • Independent consumers calculate moving averages and portfolio value live
  • Every event is stored in a PostgreSQL database for later analysis
Source code

Galaxy Collision

C++, raylib

3D simulation of the future collision between the Milky Way and Andromeda.

  • Models both galaxies as an N-body system under gravity
  • Shows in real time how tidal arms form during the merger
